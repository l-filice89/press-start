## Challenges and growth areas

### Responsive behavior was specified too late

Per-story mocks validated placement and local interaction, but did not fully model whole-feature behavior across all supported widths. Post-story work was still required for desktop and tablet command rows, including exact 694/695 and 1023/1024 boundary behavior.

System lesson: a UI gate must validate behavior across screen classes and states, not only a representative static placement.

### Story completion was below the final UX altitude

Each story could be individually complete while the integrated feature still needed responsive composition work. Final epic-level UX review happened after story closeout.

System lesson: retain per-story gates, then add one integrated responsive review before a UI epic is marked complete.

### Review volume remained high

The four stories applied at least 39 review patches. The review net worked, but recurring focus, state-preservation, and responsive-boundary findings show specifications can name these hazards earlier.

## Key insights

1. **Discovery quality compounds implementation quality.** Strong brainstorming reduced product ambiguity before development began.
2. **Pure derivation was the decisive architecture choice.** It kept recommendations explainable, deterministic, cheap, and independently testable.
3. **UI approval must cover behavior, states, and breakpoints.** Static placement approval alone cannot certify a responsive feature.
4. **Story-done and epic-UX-done are different gates.** Whole-feature composition deserves an explicit closeout review.
5. **Exact boundary evidence prevents responsive ambiguity.** Tests at both sides of every layout transition are stronger than representative viewport checks.

## Significant discoveries

No product or architecture discovery invalidates planned future work. Epic 14 is not defined, so no next-epic rewrite is required.

Process discovery: current UI-MOCK-GATE operates at story-placement altitude. Future UI work needs a responsive behavior matrix plus epic-level integrated review.
